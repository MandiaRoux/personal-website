# Personal website

This project is a React app built with [Vite](https://vite.dev/) and managed with npm.

## Available scripts

### `npm run start`

Starts the Vite development server at [http://localhost:5173](http://localhost:5173).

### `npm test`

Runs the Vitest test suite in watch mode.

### `npm run build`

Builds the production app into the `dist` directory.

### `npm run preview`

Serves the production build locally for verification.

## Content and enquiries

Service descriptions and selected projects are in `src/content.js`. Project descriptions reflect the
existing portfolio; no client testimonials or performance metrics are invented.

Copy `.env.example` to `.env.local` and set `VITE_CONTACT_EMAIL` to display a
direct email alternative (defaults to mandiaroux@gmail.com). Confirm `VITE_FORM_ENDPOINT` in your Formspree account
and verify inbox delivery before publishing. Vite environment variables are
public and require a rebuild when changed.

The incorrect RouxtAccess link has been removed until its correct URL is known.
